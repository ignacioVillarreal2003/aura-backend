# Text Cleaners

Este módulo contiene diferentes text cleaners para normalizar texto según el uso.

## 1. SpaceTextCleanerAdapter

### 📝 Descripción

Limpia espacios múltiples y líneas vacías, preservando todos los caracteres y saltos de línea originales.

## 2. FullTextCleanerAdapter

### 📝 Descripción

Limpieza completa: normaliza espacios, elimina caracteres no deseados, ajusta puntuación y mantiene párrafos estructurados.

## 3. NoLineBreaksTextCleanerAdapter

### 📝 Descripción

Elimina todos los saltos de línea y deja el texto corrido, normalizando los espacios entre palabras.
